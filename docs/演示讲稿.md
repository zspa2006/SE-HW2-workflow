# 55 秒演示讲稿

演示使用默认离线策略，不消耗模型额度。已提供 `演示视频.mp4`，54 秒、1280×720、无旁白，展示实际产物的字幕讲解。该视频不是实时录屏；以下提纲可用于自行现场演示或录制旁白。

| 时间 | 操作 | 讲解 |
| --- | --- | --- |
| 0–8 秒 | 展示标题和流程 | 我是潘彦博，学号 2404080334。DocFlow 用分析、文档、审校三个 Agent 完成 Python 代码文档工作流。 |
| 8–18 秒 | 执行下方返修演示命令 | 分析 Agent 先安全读取源码，提取函数、类和行号，文档 Agent 再依据共享证据生成说明。 |
| 18–31 秒 | 查看消息表与第一轮审校 | 这里的演示开关故意遗漏一个章节。审校 Agent 发现缺少“验证建议”，将问题发回文档 Agent，再次审校后通过。 |
| 31–43 秒 | 展示 state 与最终文档 | 每条消息都有发送者、接收者和产物，输出带源码行号。逐步结果与事件日志都保存在独立运行目录中。 |
| 43–55 秒 | 展示恢复演示结果 | 在分析节点完成后暂停，再恢复只执行文档和审校。项目支持有限重试、源码哈希校验，并附有完整测试与设计说明。 |

```powershell
python -m docflow run --root examples/shop --files pricing.py orders.py --demo-revision
```

注意明确区分：离线模式采用 AST、规则与模板；可选 LLM 模式让三个角色分别请求模型。不要将本地模拟接口测试称作真实云端模型调用。
