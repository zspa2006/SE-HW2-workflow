# 演示讲稿

演示视频为 54 秒，使用中文说明字幕，无旁白。内容来自离线模式的运行结果。现场演示时可以使用下面这段讲解：

这次作业我做的是代码文档生成流程。分析 Agent 先读取 Python 文件，提取函数、类和行号；文档 Agent 根据这些结果生成说明；最后由审校 Agent 检查章节和接口是否完整。

这里加上 `--demo-revision`，让初稿故意漏掉“验证建议”。第一次审校发现缺章，返回具体问题，文档 Agent 补齐后再次通过。消息表里可以看到每一步由谁发送、传给谁，修改前后的结果也都有保留。

分析后还可以暂停，再从文档节点恢复，不用重新分析。流程通过配置定义，新增 Agent 的例子放在 `scripts/extend_demo.py`。目前离线流程和自动测试都可以运行，模型接口使用本地模拟服务做了测试。

演示命令：

```powershell
python -m docflow run --root examples/shop --files pricing.py orders.py --demo-revision
```
