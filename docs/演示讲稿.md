# 演示讲稿

演示视频约 59 秒，展示离线模式下选择文件、运行工作流和查看生成文档的过程。现场演示时可以使用下面这段讲解：

这次作业我做的是代码文档生成流程。分析 Agent 先读取 Python 文件，提取函数、类和行号；文档 Agent 根据这些结果生成说明；最后由审校 Agent 检查章节和接口是否完整。

这里选择“分析自己的 Python 文件”，输入项目目录，再依次选择 `pricing.py` 和 `orders.py`。提交后，三个 Agent 按顺序完成任务，消息表里可以看到每一步由谁发送、传给谁。生成的文档包含函数签名、参数要求和源码行号，可以对照原代码查看。

分析后还可以暂停，再从文档节点恢复，不用重新分析。流程通过配置定义，新增 Agent 的例子放在 `scripts/extend_demo.py`。目前离线流程和自动测试都可以运行，模型接口使用本地模拟服务做了测试。

演示命令：

```powershell
python main.py
```
