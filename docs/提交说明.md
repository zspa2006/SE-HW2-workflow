# 提交说明

潘彦博　2404080334

解压 `2404080334潘彦博.zip`，进入 `2404080334潘彦博/docflow-workflow/`。主要文件是：

- `README.md`：运行方法。
- `Design.md`：流程图、架构、Agent 通信和状态管理。
- `docflow/`：源代码。
- `tests/`：自动测试。
- `docs/evidence/`：正常、返修和恢复三组运行结果。
- `docs/演示视频.mp4`：约 59 秒的实际操作录屏，展示选文件、生成文档和查看结果。

在项目目录运行：

```powershell
python main.py
```

菜单可以选择示例、自选文件、返修或恢复。使用参数命令也可以运行：

```powershell
python -m docflow run --root examples/shop --files pricing.py orders.py --demo-revision
python -m unittest discover -s tests -v
```

查看扩展方式可以运行 `python scripts/extend_demo.py`，说明见 Design 第 7 节。

包中还有 `repository.bundle`，需要 Git 仓库时可以执行 `git clone repository.bundle docflow-restored`。`MANIFEST.json` 保存各文件的 SHA-256。
